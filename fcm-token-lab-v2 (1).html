FCM Token Lab

Generate device token FCM dari browser ini, lalu catat ke Firestore. Semua kredensial disimpan cuma di browser kamu sendiri (localStorage), tidak dikirim kemana pun selain ke Firebase project milikmu.

1. Firebase config

Ambil dari Firebase Console → Project Settings. VAPID key ada di tab Cloud Messaging.

2. Generate & catat token

Browser akan minta izin notifikasi, lalu mendaftarkan token ke Firestore koleksi device_tokens.

izin: belum diminta

Sudah punya token FCM yang valid dari sumber lain? Masukkan manual di sini, langsung tersimpan ke Firestore tanpa perlu izin notifikasi browser ini.
